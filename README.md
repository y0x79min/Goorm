# PHP 로그인과 게시판

구름 실습에서 만든 PHP 웹 페이지입니다. 회원가입과 로그인을 구현하고, 로그인한 사용자가 게시글을 읽고 글과 댓글을 남길 수 있게 연결했습니다.

로그인에 성공하면 세션을 만들고 메인 화면으로 보냅니다. 메인 화면에 들어올 때는 세션을 먼저 확인합니다. 게시글을 열면 본문과 댓글을 같은 화면에서 볼 수 있습니다.

| 기능 | 파일 |
| --- | --- |
| 회원가입·로그인 | [login.php](login.php) |
| 로그인 후 메인 화면 | [main.php](main.php) |
| 게시글 작성 | [write.php](write.php) |
| 게시글과 댓글 보기 | [view.php](view.php) |

이 실습의 PHP 화면 일부는 이후 학부 웹 침입 탐지 프로젝트에서 요청을 받아 보는 웹 화면에도 사용했습니다.
